# 高清直拍专用版（jianying-editor-hd-fancam）

剪映「高清直拍 / 饭拍」固定栏目专用：把能写进草稿的参数提前搭好，生成草稿后由你在剪映精修并导出。通用版在 `jianying-editor`，本版已删掉通用功能（录屏、影视解说、TTS、云端素材、花字、自动导出、examples 等）。

## ⚠️ SVIP 与人工边界

- **你已开剪映 SVIP**。歌词识别、字幕导出、美颜美体预设 zzm1、声音分离、高清增强滤镜、ZY INNOCENT 字体等功能在剪映里可能需要会员权限——请确认登录的是 SVIP 账号；会员过期这些步骤会失效，skill 无法绕过，遇到权限提示以剪映实际界面为准。
- 本 skill 是**草稿生成器**，不操作剪映界面、不控制 AE：AI 识别 / 美颜 / 声音分离、AE 变形稳定器、最终导出，全部人工。

## 工作流（三段）

1. **剪映粗剪【人工】**：导入 R7 4K60p → 调整到 9:16 → 歌词识别 → 选片段 → 美颜美体 zzm1 → 导出隐藏字幕的中间片；同时导出歌词 SRT。
2. **AE【人工】**：变形稳定器（Warp Stabilizer）渲染导出，得到稳定片 mp4。
3. **剪映精修【skill 搭草稿 + 人工补】**：滤镜高清增强 80 / 锐化 50 / 竖排字幕（左上留安全边距、渐显渐隐、黑色阴影 40 / 4 / 2 / -45）/ 复制视频轨复合片段模糊 20 / HuHu 文字蒙版；人工补声音分离（人声 +3.0、背景音乐 -1.0）、关键帧微调、其余调节、竖排（代码不支持时手动改）。
4. **导出【人工】**：4K60p / VBR 100 Mbps。

## 交接方式（只需给一个路径）

把 **AE 导出的稳定片 mp4** 和 **剪映导出的歌词 SRT** 放进同一个文件夹，推荐同名，例如 `huhu_stable.mp4` + `huhu_stable.srt`（靠扩展名区分即可）。只把文件夹路径告诉我，我自动识别这两个文件，不需要分别给路径。

默认交接目录：

```
C:\Users\你的用户名\WorkBuddy\spaces\2026_11_25_08-23-45\handoff
```

⚠️ SRT 时间戳基于剪映里的原始片段；AE 稳定后若视频时长变了，字幕需重新对齐。

## 固定参数（实测 ID，直接用）

- 滤镜「高清增强」：`resource_id = 7426668776491453707`，80% → `value = 0.8`
- 调节（锐化等）：挂在 `type="mixed"` 轨，10 参数共用 `resource_id = 7416258989467374091`
- 顺序陷阱：`materials.effects` 是共享键，**先写调节、后写滤镜**，反了滤镜轨会空
- 字幕阴影：黑色 / 不透明度 40 / 模糊度 4 / 距离 2 / 角度 -45
- HuHu 文字蒙版：ZY INNOCENT / 不加粗 / 无下划线 / 斜体 / 字号 23 / 位置 x 0、y -2534 / 蒙版阴影 40-3-1--45
